# eNSP Network Config Skill

面向华为 eNSP 实验与网络项目的通用 Skill。

## 功能

- 识别拓扑中的设备、链路、端口、地址、VLAN 和路由区域
- 读取项目需求、拓扑截图、已有配置和验证结果
- 建立并保存网络规划基线
- 区分简单配置和分阶段配置
- 根据需求推导协议、功能和配置依赖
- 使用可迁移的设计规则辅助网络设计
- 生成按网络层次和依赖顺序组织的 VRP 阶段配置脚本
- 校验配置脚本的结构、命令、安全性和设计一致性
- 根据人工确认或运行证据推进阶段验证门禁
- 诊断配置冲突、验证失败和返工范围
- 拼接阶段脚本生成全网完整配置
- 导入并校验经过授权的 eNSP 案例
- 区分来源观察、静态校验和运行验证证据

## 基本工作流

1. 用户提供 eNSP 拓扑截图或项目文件、网络需求，以及已有配置或终端输出。
2. Skill 识别设备、链路和地址，整理网络规划，并列出端口、模块或需求方面的不确定项。
3. 用户确认规划基线；简单拓扑生成一个阶段，复杂拓扑按接入、汇聚、核心、路由、服务和安全等阶段拆分。
4. Skill 为当前阶段生成 VRP 配置脚本和验证命令。
5. 用户在 eNSP 中按设备执行脚本，再执行验证命令；Skill 不直接操作 eNSP。
6. 用户把终端输出、连通性结果或截图发回 Skill。
7. Skill 根据证据判定阶段通过、失败或待确认：通过后进入下一阶段，失败则定位问题并生成最小返工方案。
8. 全部阶段通过后，Skill 生成全网验收结果和最终完整配置。
